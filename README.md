Этот репозиторий содержит **только статические файлы** клиентской части проекта «Мои AI Новости» – персонализированного агрегатора новостей с искусственным интеллектом.

## О проекте

«Мои AI Новости» – это сервис, который ежедневно собирает новости из ваших любимых источников (Telegram-каналы, VK-сообщества, RSS-ленты, YouTube, GitHub, Reddit, Google News и др.), обрабатывает их с помощью AI (перевод, суммаризация, фильтрация), и доставляет вам персонализированный дайджест в мессенджеры Telegram или MAX, а также в браузерное PWA-приложение.

### Возможности

- ✅ Объединение любых источников в одной ленте.
- ✅ Интеллектуальная обработка: удаление дублей, рекламы, мата, донатов, хештегов.
- ✅ Автоматический перевод иностранных новостей на русский.
- ✅ Суммаризация обсуждений в Telegram-группах.
- ✅ Выбор времени получения дайджеста (для платных тарифов).
- ✅ Ручной запуск сбора новостей.
- ✅ Управление подписками через веб-интерфейс.
- ✅ PWA – установка на экран «Домой» на мобильных устройствах.

### Готовые приложения

В папке [`webapp/app/`](https://github.com/PRO-Interior-Design-proid-studio/My_AI_News_Aggregator/tree/main/webapp/app) находятся собранные установочные файлы для разных платформ:

- **Android** – `AI_News.apk` и `AI_News.aab` (для Google Play)
- **Windows** – `.msixbundle`, `.appxbundle`, `.msix` и скрипт установки `install.ps1`
- **iOS** – приложение распространяется как PWA (установка через Safari)

Эти файлы позволяют быстро установить приложение на устройства без посещения официальных магазинов.

### Используемые технологии (фронтенд)

- Vanilla JavaScript
- HTML5 / CSS3
- Telegram WebApp API
- MAX WebApp API (Bridge)
- Service Worker для PWA

## Содержимое репозитория

- `webapp/` – все HTML-страницы, стили, скрипты, изображения и иконки.
- `webapp/app/` – готовые установочные пакеты для Android и Windows.
- `robots.txt` – инструкции для поисковых роботов.

## Как это работает

Этот репозиторий автоматически синхронизируется с живым сервером. Все изменения в публичных файлах (страницы, стили, скрипты) попадают сюда каждый день.
