3. Обрабатываемые персональные данные
-------------------------------------

### 3.1. Перечень ПД, которые Оператор получает и обрабатывает:

-   **Идентификаторы в российских ID-сервисах и мессенджерах:**
    `telegram_id` (при использовании Telegram-бота), `max_user_id` /
    `max_chat_id` (при использовании MAX-бота), `vk_user_id` (при
    использовании VK-бота), `yandex_id` (при авторизации через Яндекс
    ID). Эти идентификаторы используются исключительно для
    персонализации лент и направления уведомлений.
-   **Email (при регистрации по почте):** используется для входа в
    Сервис, отправки кодов подтверждения при регистрации и
    восстановления пароля. Хранится с использованием средств защиты.
-   **IP-адрес и технические параметры соединения** (дата/время запроса,
    User-Agent, код ответа сервера) -- собираются автоматически в
    журналах доступа для обеспечения безопасности и стабильной работы
    Сервиса (защита от DDoS, анализ ошибок). Эти данные обезличиваются
    при анализе.
-   **Платёжная информация** -- не обрабатывается и не хранится
    Оператором. Все платежи проходят через стороннего агрегатора
    (Robokassa), который самостоятельно обрабатывает данные банковских
    карт и иных платёжных средств в соответствии со своей политикой
    конфиденциальности. Оператор получает только подтверждение об
    успешной оплате и идентификатор транзакции для активации подписки.

Регистрация по электронной почте, телефону или логину не предусмотрена,
поэтому такие данные не собираются.

### 3.2. Когда и какие данные собираются в разных каналах

-   **Telegram-бот:** собирается `telegram_id`, IP-адрес, User-Agent --
    при запуске бота, использовании команд, добавлении источников через
    WebApp.
-   **MAX-бот:** собирается `max_user_id`, `max_chat_id`, IP-адрес,
    User-Agent -- при запуске бота, использовании команд, открытии
    WebApp через MAX.
-   **VK-бот и VK Mini App:** собирается `vk_user_id`, `vk_chat_id`,
    IP-адрес, User-Agent -- при запуске бота, использовании команд,
    открытии Mini App.
-   **Яндекс ID (авторизация):** собирается `yandex_id` -- при входе
    через Яндекс, после успешной авторизации.
-   **Веб-приложение (PWA) и браузерная версия:** собирается
    `X-Auth-Token` (сессионный токен), IP-адрес, User-Agent, список
    источников, настройки -- при авторизации, добавлении/удалении
    источников, просмотре ленты, изменении настроек. **При регистрации
    по почте** собирается email и пароль.
-   **Браузерные расширения:** не собирают данных самостоятельно, только
    открывают PWA.
-   **Лендинг (сайт):** собирается IP-адрес, User-Agent, дата/время
    запроса (стандартные логи) -- при посещении страниц.
-   **Мобильные приложения (APK, PWA на iOS):** собираются те же данные,
    что и в веб-приложении.

Все данные собираются только в объёме, необходимом для предоставления
соответствующей функциональности.

4. Цели обработки персональных данных
-------------------------------------

Оператор обрабатывает ПД исключительно для следующих целей:

-   Предоставление пользователю персонализированной ленты новостей на
    основе выбранных им источников.
-   Управление подписками пользователя (добавление/удаление источников,
    изменение настроек).
-   Обработка платёжных транзакций, включая автоплатежи (рекуррентные
    списания), через платёжного агрегатора (подтверждение оплаты,
    активация/деактивация подписки).
-   Техническая поддержка и решение возникающих проблем (ответы на
    запросы пользователей).
-   Обеспечение безопасности Сервиса (журналирование действий, защита от
    несанкционированного доступа).
-   Исполнение требований налогового законодательства (формирование
    отчётности по доходам).
-   **Аутентификация и идентификация пользователя по электронной почте**
    (вход, регистрация, восстановление пароля).

Обработка не осуществляется для целей, не указанных выше. В частности,
персональные данные пользователей **не используются для рекламных или
маркетинговых целей**, в том числе для продвижения каких-либо источников
новостей. Сервис не передаёт персональные данные владельцам источников и
не использует их для формирования рекламных предложений.

**Персональные данные пользователей не используются для обучения моделей
искусственного интеллекта** без явного отдельного согласия пользователя.
Обработка Контента с помощью ИИ осуществляется автоматически и не
предполагает доступа к ПД пользователя.

5. Условия обработки, хранения и передачи
-----------------------------------------

### 5.1. Хранение ПД:

-   ПД хранятся в электронном виде в информационной системе Оператора,
    размещённой на серверах хостинг-провайдера, находящихся на

-   **Срок хранения:** не более 3 (трёх) лет с момента последней
    активности пользователя, если иное не требуется для исполнения
    налоговых обязательств (чеки и платежи хранятся 5 лет согласно НК
    РФ). По истечении срока или при отзыве согласия -- ПД уничтожаются.
-   **Пароли:** хранятся в открытом виде (по архитектурному решению) в
    базе данных. Доступ к БД ограничен и защищён паролем, доступ имеют
    только администраторы. Пользователь не может изменить пароль
    самостоятельно, но может запросить его повторную отправку через
    функцию «Забыли пароль?».

### 5.2. Передача ПД третьим лицам:

-   ПД не передаются третьим лицам, за исключением:
    -   **Платёжному агрегатору** (информация о сумме и идентификаторе
        пользователя для проведения транзакции, а также для
        осуществления автоплатежей (рекуррентных списаний) в
        соответствии с условиями Публичной оферты; сами банковские
        данные агрегатору не передаются).
    -   **Хостинг-провайдеру** (в рамках предоставления вычислительных
        ресурсов) -- на основании договора, где провайдер обязуется
        соблюдать конфиденциальность.
    -   По запросу уполномоченных государственных органов в случаях,
        предусмотренных федеральным законом.
-   **Трансграничная передача не осуществляется.**
-   **Оператор не передаёт персональные данные владельцам источников
    новостей, выбранных пользователем, и не использует их для рекламы
    или продвижения таких источников.**

6. Использование искусственного интеллекта (ИИ)
-----------------------------------------------

6.1. В рамках Сервиса Оператор может применять технологии искусственного
интеллекта для автоматической обработки текстов, включая, но не
ограничиваясь: перевод на русский язык, суммаризацию (краткое
изложение), фильтрацию рекламы и нежелательного контента, ранжирование и
дедупликацию новостей.

6.2. Работа ИИ основана на алгоритмах машинного обучения, которые имеют
вероятностную природу. Результаты обработки текстов могут быть:

-   неполными или неточными;
-   изменяющими смысл исходного текста;
-   непредсказуемыми и недетерминированными (один и тот же текст при
    повторной обработке может дать разные результаты);
-   содержать ошибки, логические неточности или искажения.

6.3. Оператор **не гарантирует** достоверность, точность, полноту,
релевантность или соответствие ожиданиям пользователя результатов,
полученных с помощью ИИ. Пользователь принимает на себя все риски,
связанные с использованием таких результатов, и **не вправе предъявлять
претензии** к Оператору в связи с качеством, содержанием или
последствиями использования контента, обработанного ИИ.

6.4. Пользователь подтверждает, что он ознакомлен с особенностями работы
ИИ и согласен с тем, что Сервис предоставляет обработанный контент «как
есть» (as is) без каких-либо гарантий со стороны Оператора.

6.5. Персональные данные пользователей **не используются для обучения
моделей ИИ** без явного отдельного согласия пользователя. ИИ
обрабатывает только Контент из открытых источников, выбранных
